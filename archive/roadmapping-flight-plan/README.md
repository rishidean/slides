# Flight Plan

Workshop deck — Authoring roadmaps for agents. Sequel to [Getting Airborne](../airborne/).

Live: https://slides.rishidean.com/roadmapping/

Static deck. `index.html` loads `deck-stage.js` and `support.js` by relative path — keep them side by side. `_ds/` holds the design system bundle, `uploads/` the workshop source material. `.nojekyll` stops GitHub Pages from running Jekyll over the files.
