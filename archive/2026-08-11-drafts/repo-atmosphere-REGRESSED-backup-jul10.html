A quick caveatSelf-paced

This is one way.
Not the way.

There are many ways to build software that maintains itself. This is the architecture I've been flying, stripped down to the core loop. The frontier is moving fast; some of this may be obsolete by the time you build your own.

Take the principles, not the plumbing. The shape of the loop — observe → compile → free the model — matters more than which file does what.

The parser assumed every CV looked one way.

This is the wound: prescriptive software, written once, for a world that won't hold still.

Why airborne isn't enoughSelf-paced

Three cracks in airborne-only.

01 · Cost

Full price, every time

Every action hits the model. Cost scales with usage; usage is exponential. You're penalized for success.

02 · Memory

It never learns

Every session starts cold; corrections evaporate. The system is smart, but no smarter on day 100 than day 1.

03 · Observability

Can't audit a guess

No single front door. You can't reproduce, verify, or trust what you can't see it do.

github.com/rishidean/<harness-repo> · Teaching talk
The inversionSelf-paced

The LLM is the compiler, not the runtime.

Today

LLM as runtime

You put a model on the process. It reasons about the same insertion order for the four-hundred-and-first time. Faster, but it never learned.

The inversion

LLM as compiler

It interprets the order it hasn't seen, a human validates, the system extracts the reusable logic into a deterministic path. The next order never touches the model.

The goal inverts too: use less AI over time. Measure success by the model calls you've eliminated.

The payloadSelf-paced
The org compiles itself.

"AI-powered company" is the wrong goal; the goal is the operations that no longer call the model at all. Compiling business operations is Apollo — it runs on the same flywheel you watched compile "take me to the airport" live. The rocket wasn't built to refactor your code. It was built to compile your company.

The askSelf-paced

One process. 30 days.

Pick the single operation that reasons from scratch every time — the insertion order re-read for the four-hundredth time, the ticket triaged by hand, the weekly deck built from the same five sources. Put an LLM behind one front door, log every run, add a graduation gate, and compile one path down to zero model calls.

Don't aim for the Enterprise; aim for your first rule. The era of prescriptive software is ending, and the teams that build the graduation gate first win.
